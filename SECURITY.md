# Segurança

Relate vulnerabilidades de forma privada aos mantenedores do repositório.
Não inclua segredos, dados pessoais ou código confidencial em issues públicas.

O TechLeadTools não envia telemetria nem realiza chamadas de rede. A extensão
lê a seleção atual e a área de transferência apenas quando um comando é
acionado explicitamente pelo usuário. O comando **Colar com TLT** navega até um
arquivo; ele não insere nem altera código.
